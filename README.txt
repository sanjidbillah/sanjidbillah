MASUM BILLAH — EDITABLE PORTFOLIO

Open index.html in a browser to view the site.

Edit these files:
- index.html: page copy, work order, experience, contact links
- styles.css: typography, colors, layout and responsive styling
- app.js: project detail content and interactions
- assets/: portrait, app screenshots, fonts and resume

Keep all files and the assets directory together. No build step or dependencies are needed.
To host the site, upload the contents of this folder to a static web host.

The showcase order is Battery Service, aamarPay, Neeramoy Doctor & Patient, Renessa HRM.
